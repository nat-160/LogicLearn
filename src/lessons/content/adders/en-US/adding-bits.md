# Adding in binary

- Computers store numbers in **binary**: each digit (a **bit**) is 0 or 1.
- Adding two bits:
  - 0 + 0 = 0
  - 0 + 1 = 1, and 1 + 0 = 1
  - 1 + 1 = **10** in binary (two): write 0, **carry** 1 – just like 5 + 5 = 10.
- So adding two bits gives two outputs: the **sum** bit S and the **carry** bit C.

| A   | B   | C (carry) | S (sum) |
| --- | --- | --------- | ------- |
| 0   | 0   | 0         | 0       |
| 0   | 1   | 0         | 1       |
| 1   | 0   | 0         | 1       |
| 1   | 1   | 1         | 0       |

- Look at each output column on its own: do you recognize them?
