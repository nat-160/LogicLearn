# Practice: do they match?

- Light **X** is A AND B. Light **Y** is A XNOR B ("the inputs match").
- **Your task:** predict both lights for every row, then check.

<!-- hints -->

- XNOR is 1 when both inputs are the **same** – both 1, or both 0.
- Only the row A = 0, B = 0 differs: the inputs match, so Y is 1, but X is 0.
