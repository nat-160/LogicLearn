# If … then

- "**If** it rains, **then** I take an umbrella." When is that promise **broken**?
  - Only when it rains **and** I don't take an umbrella.
  - If it doesn't rain, I kept my promise – umbrella or not.
- So "if A then B" is 0 only on the row A = 1, B = 0. It's the same as (NOT A) OR B.
- A false "if" never breaks the rule. That's the part people miss.
- The example circuit is (NOT A) OR B. Try all four rows.
