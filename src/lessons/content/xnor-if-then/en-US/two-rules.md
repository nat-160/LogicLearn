# Two rules at once

- A word problem with two rules (the author will add the story):
  - Rule 1: **if A then B**.
  - Rule 2: **not both B and C**.
- **Your task:** light **Y** when **both rules** are kept.
- Method: build each rule on its own, then join them with AND.

<!-- hints -->

- Build each rule on its own first. You built rule 1 in the last step. Which gate means "not both"?
- Y needs **both** rules to be kept at once. Which gate means "both"?
