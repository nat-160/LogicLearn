# Practice: a false "if"

- Light **X** is A AND B. Light **Y** is "if A then B" – (NOT A) OR B.
- **Your task:** predict both lights for every row, then check.
- For Y, ask: is the rule **broken** in this row?

<!-- hints -->

- The rule "if A then B" is only broken when A is on and B is off.
- When A is off, the rule can't be broken, so Y is 1 – but X (AND) is 0. That's where they differ.
