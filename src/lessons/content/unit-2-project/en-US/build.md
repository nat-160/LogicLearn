# Build the display

- **The rule** (on the right) lists which segments each number lights.
- Take **one segment at a time**: its column is a small truth table with 4 rows. Build a circuit for it, the way you learned in Lesson 7.
- Press **Check my project** when every segment is connected.

<!-- hints -->

- Some columns are easy: compare segment g's column with switch A's.
- Segment b is on for every number. Which gate gives 1 whatever A is, if you feed it A and NOT A?
