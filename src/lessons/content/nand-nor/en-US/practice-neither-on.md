# Practice: not both, or exactly one?

- Light **X** is A NAND B ("not both"). Light **Y** is A XOR B ("exactly one").
- **Your task:** predict both lights for every row, then check.
- Which row tells them apart?

<!-- hints -->

- When **neither** switch is on, are they "both on"? No – so "not both" is true.
- Only the row A = 0, B = 0 differs: X is 1 and Y is 0.
