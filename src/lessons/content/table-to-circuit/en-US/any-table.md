# Challenge: any table

- **Your task:** build a circuit for the table on the right ("The table to build").
- Predict-first: your light stays hidden until you press **Check**.
- Tip: when two rows differ in only one input, that input doesn't matter for them – one AND can cover both.

<!-- hints -->

- Write one AND per row where Y is 1, then join them with OR. Simplify afterwards if you like.
