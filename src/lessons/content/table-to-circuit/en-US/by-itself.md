# Just one row

- **Your task:** light **Y** in **one row only**: A = 0, B = 1, C = 0. The target is in the truth table's "Y wanted" column.
- Use the method: inputs that are 0 in that row need a NOT.

<!-- hints -->

- In the row A = 0, B = 1, C = 0, which inputs are 0? Each of those needs a NOT.
- An AND gate has two inputs, but this row has three. How could two AND gates work together?
