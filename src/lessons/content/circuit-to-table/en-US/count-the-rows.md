# How many rows?

- Each input can be 0 or 1, so every new input **doubles** the number of rows:
  1 input → 2 rows, 2 inputs → 4, 3 inputs → **8**, n inputs → 2ⁿ.
- List the rows in **counting order** – 000, 001, 010, … 111 – so none is missed. The first row is always **all zeros**.
- The example is **(A AND B) OR C**. Try a few rows with the switches and compare with the table.
