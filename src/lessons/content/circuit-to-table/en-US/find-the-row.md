# Find the row

- This circuit has three inputs, so 8 rows. Its light is on in exactly **one** of them.
- **Your task:** predict every row – which one lights Y?

<!-- hints -->

- The NOT gate means B has to be **0** for the first AND gate to give 1.
- All three conditions must hold: A = 1, B = 0, C = 1. Every other row is 0.
