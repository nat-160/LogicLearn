# Unknown: not connected

- Light **Z** has no wire, so it has no signal at all.
  - Its value is **unknown**, written **X**. The light shows **?**, and an unconnected wire is drawn gray and dashed.
- X is not a third value a switch can send – it means **something is missing**, usually a wire.
- If a light shows **?** in your circuit, follow its wire back to find the gap.
